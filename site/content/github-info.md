## Latest GitHub Updates

### Learn by building together

Hackathons are a practical way to learn by making a small project with other people. Start with a focused idea, prototype it, and treat debugging and experiments as part of the learning—not as reasons to stop. The GitHub Blog describes participants using GitHub Copilot to build a frontend and connect it to an API during a hackathon.

Source: [“Hack the World: Why hackathons are still the best place to learn to build” — GitHub Blog, October 9, 2026](https://github.blog/developer-skills/career-growth/hack-the-world-why-hackathons-are-still-the-best-place-to-learn-to-build/)

### Make Copilot work better in JetBrains

In Copilot for JetBrains, use the new **Fix** action from diagnostic intentions to ask Copilot to help repair an issue. You can also control automatic MCP server startup. Enterprise administrators can set a default model for new conversations. The update requires JetBrains IDE 2025.2 or later.

Source: [“New controls and chat improvements in Copilot for JetBrains” — GitHub Changelog, October 10, 2026](https://github.blog/changelog/2026-10-10-new-controls-and-chat-improvements-in-copilot-for-jetbrains)
